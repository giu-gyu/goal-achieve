# 우리의 하루

두 사람이 각자 매일 실천할 목표를 만들고, 완료 여부와 지난 기록 및 주간·월간 달성률을 함께 보는 네이티브 안드로이드 앱입니다. Android 8.0 이상을 지원합니다.

## 사용 흐름

1. 두 사람 모두 각자의 이메일과 비밀번호로 가입합니다.
2. 한 사람이 이름을 입력하고 **새 커플 공간 만들기**를 누릅니다.
3. **우리** 탭에서 초대 코드를 공유합니다.
4. 상대방은 자신의 이름과 받은 코드를 입력해 **상대방 공간에 참여하기**를 누릅니다.
5. **오늘** 탭에서 매일 반복할 목표를 만들고 완료 또는 미완료를 기록합니다.
6. **기록** 탭의 날짜를 눌러 과거 날짜를 조회하거나 자신의 기록을 수정합니다.
7. **달성률** 탭에서 주간·월간을 선택하고 이전 기간도 조회합니다.

한 공간에는 두 계정만 참여할 수 있습니다. 목표와 기록은 두 사람에게 보이며, 두 멤버 모두 커플 공간의 데이터를 읽고 추가·수정·삭제할 수 있습니다. 목표를 종료하면 다음 날부터 목표가 표시되지 않으며 기존 기록은 유지됩니다. 같은 계정으로 로그인하면 다른 휴대폰에서도 공간이 복원됩니다.

## 실제 사용을 위한 Firebase 설정

설정되지 않은 APK에서는 **체험해보기**만 가능합니다. 체험 기록은 메모리에만 저장되며 앱 종료 시 사라집니다. 실제 데이터를 쓰려면 아래 설정 후 APK를 다시 빌드해야 합니다.

1. [Firebase Console](https://console.firebase.google.com/)에서 **프로젝트 만들기**를 선택합니다. Analytics는 이 앱에 필수가 아닙니다.
2. 프로젝트 설정에서 Android 앱을 추가합니다.
   - Android 패키지 이름: **com.together.daily**
   - 앱 닉네임: 우리의 하루
   - 이메일·비밀번호 로그인에는 SHA 인증서 등록이 필요하지 않습니다.
3. **google-services.json 다운로드**를 누르고 파일을 이 프로젝트의 **app/google-services.json**으로 넣습니다.
4. **Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호**를 사용 설정합니다. 이메일 링크 로그인은 필요하지 않습니다.
5. **Firestore Database → 데이터베이스 만들기**에서 기본 데이터베이스를 만들고 **프로덕션 모드**를 선택합니다. 가능하면 서울 리전을 선택합니다.
6. Firestore의 **규칙** 탭에 이 프로젝트의 **firestore.rules** 전체 내용을 붙여넣고 **게시**합니다. 기본 테스트 모드 규칙으로 사용하지 마세요.
7. 프로젝트를 다시 빌드한 뒤 같은 APK를 두 휴대폰에 설치합니다.

Firebase 계정이나 서버 관리 비밀키는 앱에 넣지 않습니다. google-services.json은 앱 연결 설정 파일입니다. 실제 데이터가 쌓이기 전에 본인의 Firebase 프로젝트에 위 규칙이 게시되어 있는지 확인해주세요.

안내 근거: [Firebase Android 연결](https://firebase.google.com/docs/android/setup), [이메일·비밀번호 인증](https://firebase.google.com/docs/auth/android/password-auth), [Firestore 보안 규칙](https://firebase.google.com/docs/firestore/security/rules-conditions).

## 빌드

Android Studio에서 이 폴더를 열고 Gradle 동기화를 마친 뒤 **Build APK(s)**를 실행합니다. JDK 17, Android SDK 35, Gradle 8.11.1을 사용합니다.

이 작업 폴더에 내려받은 빌드 도구를 사용할 때는 PowerShell에서:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./build.ps1
```

생성 위치: app/build/outputs/apk/debug/app-debug.apk

Firebase 설정 파일이 없더라도 빌드는 가능하며 체험 모드로 동작합니다. 파일이 추가되면 Google Services 플러그인이 자동 적용됩니다.

## 휴대폰에 설치

APK를 카카오톡, USB 또는 클라우드 드라이브로 휴대폰에 전달하고 파일을 열어 설치합니다. 파일을 여는 앱에 대해 Android의 **이 출처 허용**을 켜야 할 수 있습니다. Android 8.0 이상이 필요합니다. 플레이스토어 등록 없이 두 사람의 휴대폰에 직접 설치할 수 있습니다.

APK 업데이트는 같은 서명 키로 빌드해야 합니다. 이 폴더의 .tools/debug.keystore를 보관하세요. 설정이 바뀐 APK를 설치하기 전에 기존 앱을 지울 필요는 없습니다.

## 계산 기준

- 완료율 = 완료한 날 / 대상 날짜 수 × 100, 정수 반올림.
- 대상 날짜: 선택한 주 또는 달과 목표의 시작~종료 기간이 겹치는 날 중 오늘까지.
- 미완료와 미기록은 별도로 표시하며 모두 분모에 포함합니다.
- 목표 생성 전·종료 후·미래 날짜는 제외합니다.
- 주간은 월요일~일요일, 월간은 해당 월의 1일~마지막 날입니다.
- 날짜 기준은 Asia/Seoul입니다. 목표 종료일도 대상 날짜에 포함합니다.

## 검증

계산 로직의 JUnit 테스트와 Firestore 접근 규칙에 대한 로컬 에뮬레이터 테스트를 제공합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./build.ps1 -TestOnly
```

규칙 검사는 실제 Firebase 프로젝트를 건드리지 않으며 demo-together 로컬 에뮬레이터에만 요청합니다:

```powershell
& '.tools/jdk/jdk-17.0.20.1+1/bin/java.exe' -jar '.tools/firestore-emulator.jar' --host=127.0.0.1 --port=8080 --project_id=demo-together --rules=firestore.rules
# 별도 터미널
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/firestore-rules.ps1
```

## 현재 범위

매일 반복 목표, 두 계정 공간, 실시간 조회, 기록 수정·취소, 목표 종료, 기간별 통계를 제공합니다. 알림, 특정 요일 반복, 계정 삭제, 커플 해제 및 데이터 내보내기는 현재 포함하지 않습니다. 초대 코드는 상대방에게만 공유하세요. 코드가 있으면 로그인한 사용자는 참여 전 공간의 이름 목록을 읽을 수 있고 빈 두 번째 자리에 참여할 수 있습니다. 목표·기록은 참여자만 조회할 수 있습니다.

네트워크 연결이 끊기면 캐시된 기록을 조회할 수 있으며 저장 요청은 연결 복구 후 반영됩니다. 실제 프로젝트 연결, 두 실기기 동기화와 설치 확인은 설정 파일을 받은 후 진행해야 합니다.


## 디자인 업데이트 (1.1.0)

오늘 화면의 한 주 날짜 표시를 누르면 해당 날짜의 기록으로 이동합니다. 기록 화면에서는 달력으로 날짜를 고릅니다. 목표의 메뉴(점 세 개)에서 기록 취소 또는 목표 종료를 선택할 수 있습니다. ‘우리’ 탭에서 초대 코드 복사도 가능합니다.

최신 설치 파일은 artifacts/together-daily.apk입니다. 두 휴대폰 모두 같은 파일로 업데이트하면 됩니다. 기존 앱을 지우지 말고 덮어 설치하세요. 휴대폰에는 내장 저장공간 최상단과 다운로드 폴더에 together-daily.apk로 복사해 두었습니다.


## 목표·메모 업데이트 (1.2.0)

- 오늘 화면은 오늘 날짜에 해당하는 평일 또는 주말·공휴일 목표만 자동 표시합니다. 목표 수정에서 오늘의 공동 날짜 분류를 변경할 수 있으며 그날의 기록·메모·달성률에도 반영됩니다. 목표 수정은 상단 평일/주말 탭의 분류를 유지하며 카드별 분류 선택은 제공하지 않습니다. 기존 목표는 평일 목표로 읽습니다.
- 기록과 달성률은 평일의 나·상대방 결과를 먼저, 주말·공휴일의 나·상대방 결과를 그 다음에 표시합니다. 두 분류의 결과는 합산하지 않습니다.
- 횟수 목표는 1·2·3·4·X 버튼으로 선택하며 X(기본값)는 횟수 비활성화입니다. 기존 주 5~7회 설정은 변경 전까지 보존합니다. 계산은 월요일~일요일 기준입니다. 하루에 완료 1회로 계산합니다. 주 2회 목표에 1회 완료는 50%, 2회 이상은 100%입니다. 초과 완료는 다른 주로 이월하지 않습니다. 월간은 해당 월에 포함된 주별 결과를 합산하며, 시작·종료·월 경계로 일부만 포함된 주에도 설정한 주당 목표 횟수를 적용합니다.
- 매일 목표는 해당 분류의 날짜만 달성률 분모에 포함하며 미래 날짜는 제외합니다. 기록 표의 당일 완료율과 목표별 기간 달성률은 별도로 표시합니다.
- 메모는 서버 저장 확인 후 성공을 표시합니다. 저장 중 입력 변경, 실패, 재실행 시 초안을 보관하고 서버 조회가 초안을 덮어쓰지 않습니다. 내용을 지워 저장하면 메모가 삭제됩니다. 권한 거부 시 최신 Firestore 규칙 게시 여부를 안내합니다.
- 한국 전국 공휴일·대체공휴일은 2026~2027년을 반영했습니다. 임시공휴일 추가나 이후 연도는 날짜표 업데이트가 필요합니다. 지원 연도 밖의 기록 화면은 안내를 표시합니다. 출처: [2026년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2026), [2027년 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData?search_year=2027), [우주항공청 2027년 발표](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do%3Bjsessionid%3DCz_mvwv2IbDxqRkhxd8saS5XaQ3vNa0MOXeH1DkO.homepage20?plcyBrfNo=431).
- 두 휴대폰 모두 최신 artifacts/together-daily.apk를 기존 앱 위에 설치해야 새 기능을 동일하게 사용합니다. Firebase Console에도 현재 firestore.rules를 게시해야 합니다.

## 오늘·목표 수정 개선 (2026-10-12)

- 오늘의 공동 날짜 분류는 Firestore `pairs/{pairId}/daySchedules/{date}`에 저장합니다. 달력 기본값은 다음 날 자동 적용되고 과거 변경 날짜는 기록에 유지됩니다.
- 목표 수정에서 목표 이름·주당 횟수·색상을 하나의 저장 버튼으로 저장합니다. 색상은 기존 6색을 포함한 20색이며 오늘 카드, 기록의 목표 칸, 달성률 및 정렬에 적용됩니다.
- 메모 저장 성공 후 중앙에 1.8초 동안 확인 팝업이 표시됩니다. 저장 오류는 성공 팝업을 표시하지 않습니다.
- 모든 오늘 목표에 완료 또는 미완료 기록을 저장하면 폭죽을 실행합니다. 전체 기록 상태에서 값만 변경할 때는 반복 실행하지 않고, 기록 취소 후 다시 모든 기록을 채우면 실행합니다.
- 목표 수정은 제목과 닫기 버튼을 한 줄에 배치하고 상하 여백·카드 간격을 줄였습니다. 목표 추가와 순서변경 버튼은 목록의 스크롤 맨 아래에 있습니다.
- 이번 변경은 기존 상태 보관 커밋과 요청 항목 1~9의 개별 커밋으로 구분했습니다. 실제 설치 APK도 별도 빌드 커밋으로 기록합니다.
## 기록 표·메모·인물 프로필 개선 (2026-10-12)

- 주간·월간 기록의 메모는 `10/12 (월) 메모 내용`처럼 날짜 뒤에 내용을 바로 표시합니다. 장식선과 작성자 메모 배지를 제거했으며 긴 메모는 줄바꿈하여 표시합니다.
- 목표가 없는 분류에도 목표·날짜·달성률 헤더와 당일 완료율 행을 유지합니다. 해당 목표가 없는 날짜의 비율은 빈칸입니다.
- 내 프로필에서 남자 또는 여자를 선택하면 작성자 표에 블루 또는 라벤더 색상이 적용됩니다. 성별이 미설정이면 중립 색상과 기본 인물 아이콘을 사용합니다. 평일 영역은 크림, 주말 영역은 그레이 배경으로 구분합니다.
- 내 프로필에서 얼굴·곱슬머리·금발·서 있기·걷기·달리기·인사 중 인물 이모티콘을 선택하고 프로필 저장을 누릅니다. 기록과 달성률에는 이름 뒤에 선택한 인물이 표시됩니다. 짝꿍도 자신의 계정에서 프로필을 설정하면 두 사람에게 공유됩니다.
## 정렬·오늘 전환·색상 선택 개선 (2026-10-12)

- 정렬의 가장자리 자동 스크롤을 제거했습니다. 순서변경 창은 화면 너비의 98%로 확장하고 목표 카드 양옆에 수동 스크롤 영역을 확보했습니다. 카드에서 끌면 순서 변경, 양옆 여백에서 쓸면 목록 스크롤입니다. 먼 위치로 옮길 때는 드래그를 놓고 여백을 스크롤한 뒤 이어서 옮길 수 있습니다.
- 오늘 날짜 분류는 현재 분류와 반대 분류를 안내하는 문구 및 전환 버튼으로 변경합니다.
- 목표 수정 카드의 분류 선택은 제거했습니다. 상단 탭에 속한 분류를 그대로 유지합니다.
- 20색은 가로 스크롤 없이 한 줄에 밀착된 사각형으로 표시합니다. 기존 저장 색상 0~5는 같은 색상을 유지하고 추가 색상은 6~19로 저장합니다.
## 반복 안내·목표 색상 제거 (2026-10-12, 최신 상태)

- 주당 횟수를 지정하지 않은 목표의 `해당 요일마다` 안내를 오늘·기록·달성률에서 제거했습니다. 횟수가 설정된 경우에만 `주 N회`를 표시합니다.
- 목표 추가·수정에서 색상 선택 및 개별 목표 색상 적용을 제거했습니다. 현재 목표 카드는 공통 디자인이며 기록 표의 남자 블루·여자 라벤더 색상은 유지합니다.

## 오늘 탭 날짜 이동 (2026-10-13)

- 날짜 카드의 이전 날·다음 날 버튼으로 과거와 미래 날짜를 이동하고, 오늘로 버튼으로 현재 날짜에 돌아옵니다.

## 목표 유형별 달성률·색상 (2026-10-13)

- 평일 목표는 대상 평일 전체, 주말·공휴일 목표는 대상 주말·공휴일 전체를 분모로 계산합니다. 생성일 이전·종료일 이후는 제외합니다.
- 주당 횟수를 설정하면 분류보다 우선하여 월~일 모두 기록할 수 있습니다. 매주 목표 횟수만큼 완료하면 100%, 초과분은 다음 주로 이월하지 않습니다.
- 소수점은 버립니다. 평일 4/5=80%, 주말 1/2=50%, 주 3회 목표의 월·토 완료=66%. 미래 기록은 현재 달성률에 미리 반영하지 않습니다.
- 오늘 목표 카드·기록 목표 칸·달성률 목록에 블루(평일), 틸 그린(주말·공휴일), 라벤더(주당 횟수)를 적용합니다. 유형 문구도 함께 표시합니다.

- 프로필 저장 버튼은 스크롤 내용 밖 하단에 항상 표시합니다. 저장 성공 시 창이 닫힙니다. 취소는 저장하지 않습니다.
